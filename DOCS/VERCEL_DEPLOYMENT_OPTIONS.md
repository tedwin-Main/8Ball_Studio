# Vercel Deployment Options & Presets

| Preset | Used for | Popularity / Use |
| :--- | :--- | :--- |
| **Vite** | Fast development server and production bundler for React, Vue, Svelte, and vanilla JavaScript | Excellent for interactive front-end sites. **This project uses it.** |
| **Next.js** | Full React framework: routing, server rendering, APIs, server functions, SEO | Very popular for production React websites and full-stack apps. |
| **Vue** | Vue-based user interfaces and single-page apps | Popular alternative to React. |
| **Angular** | Full application framework with routing, forms, dependency injection, and TypeScript | Common in large companies and enterprise systems. |
| **Astro** | Content-heavy sites, blogs, documentation, and marketing pages | Good performance; supports "islands" of React/Vue/Svelte. |
| **TanStack Start** | Full-stack React application with typed routing, SSR, streaming, server functions, and server routes | Modern option for advanced React apps; newer than Next.js. |
| **Create React App** | Older React starter | Legacy; avoid for new projects. |
| **Blitz.js** | Older full-stack React framework | Legacy. |
| **Container** | Deploy an app using a Docker container | For custom servers or unusual runtimes. |
| **Brunch** | Older JavaScript build tool | Rarely used now. |
